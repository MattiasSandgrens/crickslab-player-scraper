# High-Performance API-First Data Pipeline (Crickslab Match Central)

An enterprise-grade, highly scalable data engineering pipeline built to extract, clean, and visualize large-scale sports data. 

Instead of using slow and brittle HTML parsing, this project **reverse-engineers frontend network traffic (Next.js)** to target backend JSON APIs directly. This API-first architecture makes the extraction process **up to 10x faster** and highly resilient to frontend layout changes.

## 🌟 Key Features
- **API-First Architecture:** Directly intercepts internal JSON endpoints, bypassing heavy HTML layouts and client-side rendering blockades.
- **Massive Scale & Speed:** Driven by an asynchronous Python engine (`asyncio`) capable of handling **790,000+ player profiles** across **39,000+ pages** without performance degradation.
- **Advanced ETL Processing:** Implements robust data cleaning, validation, and aggregation pipelines using `pandas`.
- **Business Intelligence Integration:** Automatically structures and feeds the final datasets into a dynamic Excel dashboard featuring interactive charts and KPI cards for immediate, actionable insights.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Concurrency:** `asyncio`, `aiohttp` (Asynchronous HTTP requests)
- **Data Engineering & ETL:** `pandas`, `numpy`
